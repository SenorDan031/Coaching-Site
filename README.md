# Coaching-Site
A site which digitize maximum coaching work online in an easy to manage way. The site is based on hybrid model of LMS (Learning Management System) and RBAC (Role Based Access Control) .
This site is meant to ease up the hassle working environment of a coaching institute by digitize their most of the work. Increasing productivity and enhancing the efficiency of management.

This project is designed to streamline coaching institute operations by providing separate dashboards and functionalities for:

* 👨‍🎓 Students
* 👨‍🏫 Teachers
* ⚙️ Admins

---

# 🚀 Features

## 🔐 Authentication System

* Secure login/signup system
* Password hashing using Werkzeug
* Session-based authentication
* Role-based login architecture
